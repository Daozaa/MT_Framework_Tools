# MHGU 角色 MOD

## MT Framework Tools 1.4.17
1. 在物体模式选中 MMD 骨架或角色网格，打开 N → MTFramework → MMD 转换。
2. 需要时点「应用 MMD T 姿势」，再点「烘焙手指握持姿势」。两项会更新静止骨架、网格和形态键，可在导入 body.arc 前执行。
3. 握持默认抬腕 20°、拇指根下压 12°。按 F9 可调角度和四指力度。用旧版烘焙过的角色请从烘焙前的工程接续。
4. 导入 body.arc 后点「自动对齐身体骨骼」。双侧 MT 手骨头端对齐 MMD 手骨头端，前臂尾端接到腕关节。用 MT 手骨的头尾中点检查握把位置。场景有多副骨架时，可在面板指定要用的骨架和盆骨。
5. 对齐后可用「自动整理并迁移物理骨」归并面部和辅助骨，迁移保留的物理骨，再登记物理和绑定网格。图集入口在「TEX 贴图」。

## 嵌入贴图图集

在 TEX 栏合并贴图，选中使用当前图集 UV 的网格。在跨部位区点「带贴图导出…」并选择目标部位。输出的 ARC 内含图集 TEX，模型材质引用同一图集。普通部位按钮沿用容器贴图，TEX 栏的「导出 ARC + 独立图集 TEX」另写一份 TEX 供工坊套用。

## 连接跨组的 CTC 物理链

在物体模式下登记物理骨后，点「CTC 自定义物理骨 → 添加锁死连接骨」。跨组的子链会通过角度上限和半径都为 0 的新链根，从物理父骨尾端接到子链头端。原链保留自身物理参数和顶点权重。每条跨组链需要一个空余骨位。删除已登记骨后，连接骨按钮会同步模板和 CTC，回收不再引用的骨位。

「套用（全部）」下的「排除锁死节点」默认打开，保留角度为 0 的节点参数。

## 编辑 CCL 胶囊

展开「CCL 碰撞胶囊」，从下拉列表选择部位。可直接点「移动 A」「移动 B」或「整体移动」，滚轮调半径，左键确认，右键或 Esc 取消。半径和偏移也可直接输入。开启「左右镜像联动」后，端点和半径改动会同步到唯一配对的对侧胶囊。

## MHGU 工坊
双击「启动工坊.bat」打开程序。打开 ARC，选 MOD 后点「套用图集 TEX…」。
标准 800B 材质可用「贴图 Alpha」读取 TEX 的透明通道。
使用透明叠层时，把叠层做成独立分件，再在「网格 → 材质」给它指派该材质。
